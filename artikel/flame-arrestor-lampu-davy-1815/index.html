Flame Arrestor: Prinsip Lampu Davy 1815 yang Menjaga Vent Tangki

23 Oktober 2026 · ilmutekkim

Versi carousel: lihat di Instagram @ilmutekkim

Gas metana yang merembes di tambang batu bara pernah meledak hanya karena tersulut lampu api terbuka, dan persoalan yang sama kini mengancam vent tangki bahan bakar. Flame arrestor menjawab ancaman tersebut dengan prinsip yang ditemukan pada 1815, yaitu api yang kehilangan panasnya pada logam tidak dapat merambat lebih jauh [3][4].

Firedamp dan api terbuka di tambang batu bara

Pada awal 1800-an, tambang batu bara diterangi lampu api terbuka. Gas metana yang merembes dari dinding tambang, yang disebut firedamp, meledak setiap kali tersulut oleh api tersebut [1]. Firedamp adalah metana dengan rumus CH4 yang mudah meledak apabila tersulut api terbuka.

Persoalan pada masa itu bersifat mendasar, yaitu penambang memerlukan cahaya untuk bekerja, tetapi cahaya yang tersedia justru merupakan sumber penyulut bagi gas yang tidak terlihat. Setiap lampu yang menyala di dalam tambang membawa risiko ledakan selama firedamp terkumpul di udara tambang [1].

Ledakan Felling 1812 yang menewaskan 92 penambang

Pada 1812, tambang Felling di Inggris meledak setelah firedamp yang terkumpul tersulut lampu penambang. Ledakan tersebut menewaskan 92 orang [1]. Peristiwa itu memperlihatkan bahwa persoalan lampu tambang bukan lagi persoalan teknis kecil, melainkan persoalan keselamatan publik.

Bencana tersebut membuat publik menuntut lampu tambang yang aman. Kimiawan Humphry Davy kemudian diminta meneliti persoalan tersebut, dan penelitian yang dimulai dari tuntutan publik itu menghasilkan prinsip pengaman api yang masih dipakai sampai sekarang [2].

Lampu Davy dan kawat kasa yang menyerap panas

Davy menemukan bahwa api yang dikelilingi kawat kasa halus tidak dapat menyulut gas di luar kasa. Logam kasa menyerap panas api dengan sangat cepat sehingga suhu jatuh di bawah titik nyala metana, dan api berhenti merambat pada batas kasa tersebut [2].

Lampu uji pertama menyala di tambang Hebburn pada Januari 1816. Davy menolak mematenkan temuannya, sehingga prinsip kawat kasa tersebut dapat dipakai secara bebas sejak awal penyebarannya [2]. Penolakan paten itu menentukan perjalanan prinsip tersebut pada masa berikutnya.

Prinsip quenching pada elemen flame arrestor

Flame arrestor menerapkan prinsip yang sama melalui elemen logam dengan celah yang sangat sempit. Uap bahan bakar keluar melalui celah sempit elemen logam tanpa hambatan berarti, sedangkan api dari luar yang mencoba masuk kehilangan panasnya ke dinding logam dan padam sebelum mencapai uap di dalam tangki [3]. Mekanisme pemadaman karena panas terserap dinding logam tersebut merupakan prinsip quenching pada vent tangki.

Perbedaan arah aliran menjelaskan fungsi alat tersebut. Gas dan uap dapat melewati celah karena celah hanya menyempitkan lintasan aliran, tetapi api tidak dapat melewatinya karena perambatan api memerlukan suhu yang dipertahankan. Apabila dinding logam menyerap panas lebih cepat daripada yang dihasilkan api, rantai perambatan terputus pada elemen tersebut [3].

Penjaga vent tangki saat ini dan warisan tanpa paten

Flame arrestor modern memakai elemen pita logam berlipat dengan celah yang sangat sempit dan dipasang pada vent tangki timbun. Standar desainnya mengacu pada ISO 16852, sedangkan kebutuhan venting tangki diatur dalam API 2000 [3][4]. Tanpa alat tersebut, sambaran api pada ujung vent dapat merambat masuk dan menyulut uap di dalam tangki.

Karena Davy menolak mematenkan lampu keselamatannya, prinsip kawat kasa dipakai bebas oleh siapa pun tanpa royalti. Dua abad kemudian, prinsip yang sama menjaga vent tangki bahan bakar di seluruh dunia [2]. Lampu tambang tersebut merupakan pendahulu pengaman api modern, dan setiap vent tangki atmosferik wajib memiliki pengaman api sesuai standar yang berlaku [4].

Fakta kunci

  • Ledakan tambang Felling pada 1812 menewaskan 92 penambang setelah firedamp tersulut lampu penambang.
  • Kawat kasa pada lampu Davy menyerap panas api dengan cepat sehingga suhu jatuh di bawah titik nyala metana dan api tidak merambat keluar.
  • Lampu uji pertama Davy menyala di tambang Hebburn pada Januari 1816, dan Davy menolak mematenkan temuannya.
  • Flame arrestor modern memakai elemen pita logam berlipat dengan celah sangat sempit pada vent tangki timbun, dengan desain mengacu pada ISO 16852 dan kebutuhan venting diatur API 2000.
  • Firedamp adalah metana (CH4) yang merembes dari dinding tambang dan mudah meledak apabila tersulut api terbuka.

Kesimpulannya

Kisah flame arrestor memperlihatkan bahwa api dapat dihentikan tanpa air dan tanpa mematikan aliran gas, cukup dengan menyerap panasnya pada logam sampai suhu berada di bawah titik nyala. Prinsip yang lahir dari bencana tambang pada awal 1800-an tersebut tetap menjadi penjaga vent tangki sampai sekarang, dan penyebarannya yang luas tidak terlepas dari keputusan Davy untuk tidak mematenkan temuannya [2][3].
